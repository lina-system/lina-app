# Calculator evidence

`calculator.png` is an offscreen AppKit rendering of the production native input
and result layer using synthetic `(3+4)*12%`. The existing Flutter answer/footer
area is outside the crop. It is generated by `CalculatorContentTests` with
`LINA_CALCULATOR_CAPTURE` set to an output path; no other application or desktop
pixels are captured. This is a layout capture, not physical keyboard evidence.

`request-log.json` is generated by `node scripts/calculator.mjs` against an
ad-hoc-signed release app and a loopback synthetic Core. Its source revision and
dirty flag identify the tested tree. The app's metadata-only transport log and
the independently observed socket requests must both contain only `hello` before
calculation; the calculation interval must contain zero Core requests. The JSON
also records actual result rows, copied values and history count.

macOS CI reruns the native tests and release fixture and uploads fresh evidence
in `launcher-evidence`. Physical interaction, system-locale preferences and
VoiceOver on the reference Mac remain separate acceptance checks under #116.
