# Contributing

The LINA app is not accepting outside pull requests during alpha. Bug reports and ideas are welcome in Issues.

## Build and test

Node 24. `npm ci` installs the pinned toolchain.

- `npm test` generates the TypeScript client from `openapi/lina-client.yaml`, checks that no tracked file contains personal data, typechecks, runs the tests, and checks that a renamed schema field fails the build.
- `npm run check:personal` scans tracked files for home paths, machine host names, email addresses, personal accounts and the names in `PERSONAL_DATA_NAMES` (comma separated). Test fixtures are generated by `src/fixtures/synthetic.ts`; do not hand-write names or real data.
- `npm run build` builds the app. The version stamped into the build is `0.0.1-alpha.YYYYMMDD.N`.
- `npm run capture` builds, then takes captures at 1280 and 390 wide on synthetic data. CI uploads those captures. Do not commit them.
