## Fonts

No font file is committed. `native/web/build.sh` bundles one font into the wasm at build time:
Pretendard (SIL Open Font License 1.1, https://github.com/orioncactus/pretendard) from
`docs/research/90-accent/fonts/` when that file is in the checkout, otherwise the file named by `LINA_WEB_FONT`.
Hangul missing from that font is drawn by the browser's own fonts through GPUI's Canvas fallback.
The Mac and iOS apps use the system fonts.
